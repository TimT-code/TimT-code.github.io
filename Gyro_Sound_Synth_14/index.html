V14.1 Hotfix Upgrades:
- Preset Grid Restored: Fixed the missing `buildPresetGrid` function that caused startup crashes when parsing presets.
- Mode Buttons Restored: Fixed internal ID mapping so Theremin, Impact, Touch, etc. display correctly on the Master Control Bar.
- Advanced Draggable Clone System: Dragging a button off the control bar safely clones it. The cloned button is fully draggable on the playfield, functions perfectly, and restricts to 1 clone per button type.
- Draggable Trash Bin: Replaced the giant red top bar with a sleek, circular, floating `[✖]` trash bin that only appears when actively moving items.
- Advanced VFX Mapping: Note mapping now explicitly displays which notes are mapped inside the GUI and correctly handles specific octaves and sharps.
